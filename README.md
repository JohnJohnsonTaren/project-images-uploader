# Сервер зображень

Веб-сервіс для завантаження картинок (.jpg, .png, .gif, до 5 МБ) із прямими посиланнями.
Python-бекенд (`http.server` + Pillow) + Nginx + Docker Compose.

## Вимоги
- Docker і Docker Compose

## Запуск і зупинка
```bash
docker compose up --build      # запуск
docker compose down            # зупинка (томи images і logs зберігаються)
docker compose down -v         # зупинка + видалення завантажених файлів і логів
```

| Що | Адреса |
|---|---|
| Сайт (Nginx) | http://localhost:8080 |
| Сторінка завантаження | http://localhost:8080/upload |
| Каталог зображень | http://localhost:8080/images/ |
| Бекенд | недоступний ззовні: працює лише в мережі Docker (`http://app:8000`), доступ — тільки через Nginx |

Завантажені зображення з'являються в папці `images/`, лог — у `logs/app.log` (папки підключені до контейнерів).

Запуск без Docker (для розробки, бекенд тоді слухає `localhost:8000`):
```bash
pip install -r requirements.txt
IMAGES_DIR=./images LOGS_DIR=./logs python3 app.py
```

## Маршрути
| Метод | Шлях | Хто обробляє | Опис |
|---|---|---|---|
| GET | `/` | Nginx | Головна сторінка (на `:8000` — JSON-привітання бекенду) |
| GET | `/upload` | Nginx | Сторінка з формою завантаження |
| POST | `/upload` | Бекенд | Завантаження файлу, поле форми `file` (multipart/form-data) |
| GET | `/images/<файл>` | Nginx | Пряме посилання на зображення |
| GET | `/images/` | Nginx | Список усіх завантажених зображень |

`POST /upload` — успіх (200):
```json
{"message": "Файл успішно завантажено", "file_id": "<uuid>.png", "url": "/images/<uuid>.png"}
```
Помилки (400): `{"error": "..."}` — порожній запит, не multipart, немає файлу, непідтримуваний
формат, порожній файл, файл більше 5 МБ, вміст не є зображенням.

Приклад: `curl -F "file=@photo.png" http://localhost:8080/upload`

## Перевірки безпеки
Розширення файлу перевіряється, а вміст додатково перевіряє Pillow: перейменований `.exe` у `.png`
буде відхилено. Файл зберігається під випадковим UUID-іменем із розширенням за реальним форматом.

## Логи
Файл `app.log` у томі `logs`, формат `[Дата/час] Дія: повідомлення`:
```
[2025-01-24 14:00:00] Успіх: зображення 3f2a....png завантажено
[2025-01-24 14:01:00] Помилка: непідтримуваний формат файлу (user_file.txt)
```
Читати: `cat logs/app.log`

## Структура
```
app.py              Python-бекенд (маршрути, валідація, логування)
images/             Завантажені зображення (підключено до контейнерів)
logs/               Лог app.log (підключено до контейнерів)
requirements.txt    Залежності (Pillow)
Dockerfile          Multi-stage збірка бекенду
docker-compose.yml  Сервіси app і nginx, томи images і logs
nginx.conf          Роздача /images/, статики, проксі на бекенд
static/             Сторінки та ресурси інтерфейсу (HTML/CSS/JS/зображення)
```
